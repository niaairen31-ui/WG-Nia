# AMENDMENT-0091-03 — seed customs honour their hidden flag

Ticket: TICKET-0091   Lot: LOT-0091-lore-as-facts.md   Brief in flight: I
Decided by Nia (2026-09-22): keep the executor's implementation.

## What deviated

BRIEF-0091-I item 3, as regenerated by AMENDMENT-0091-02, told the seed
(`scripts/seed_pilot.py::ensure_location_customs`) to write each subculture
entry as a `coutume` fact "(aspect = key, not hidden)". The seed's Dernier
Verre entries include `"hidden": ("En sous-main, point d'appui de
L'Innommée.", True)`. Writing it as not hidden would give it a `location`
default at `knows`, which breaks the hidden-custom trap (invariant: a hidden
custom is never notorious). The brief's wording was wrong; the executor
stopped short of it and honoured the flag.

## Amended text (BRIEF-0091-I, Scope IN item 3, verbatim)

"through `write_entity_facets` (aspect = key; `hidden` = the entry's own
`is_hidden` flag, so a hidden entry gets no default, exactly as C-18 —
AMENDMENT-0091-03), idempotent by …"

No contract changes: C-05 already maps `hidden: True` to scope `none`, and
C-18 already migrates `is_hidden = 1` rows with no default.
